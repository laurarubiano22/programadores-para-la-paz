El comando uname -a, en sistemas Linux, muestra información del sistema operativo, como el nombre del kernel, la versión y la arquitectura del equipo.

En Windows PowerShell este comando no está disponible, por lo que utilicé systeminfo para consultar la información del sistema.

El comando whoami muestra el nombre del usuario que está utilizando el equipo.

Conocer esta información es útil para administrar un servidor porque permite identificar el sistema operativo y el usuario que ejecuta las tareas.
